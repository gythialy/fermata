## 取舍与实现提示

- **视觉尺寸 ≠ 命中区**：星期点阵在静态画板保持 20px 视觉方块，真实控件（网页/原生）的点击命中区应 **≥40px**（移动端按 ≥44px），用透明 padding 或容器按钮扩大，不要放大字或方块；文字标签仍需可读、相邻命中区不能重叠。
- 关态不使用 `role="img"` 包裹窗口（会把交互子树从无障碍树里抹掉），改用 `role="group"` + 名称；禁用态用原生 `disabled`，`aria-disabled` 只给非原生的行与星期点阵，避免「可聚焦却不能操作」的假可用。
- 关态的编辑入口整体禁用，而不是隐藏或清空：用户需要看到规则还在，才能相信开启后会恢复；总开关是唯一保留可操作的组控件。
- 摘要节奏芯片仍用松绿，是唯一的有色块；删掉灰底后靠分隔线维持分区，不新增卡片。
- 中文文案沿用 `locales/zh-Hans.json`：`settingsSkipEnablePeriods`、`settingsSkipPeriodSwitch`、`settingsSkipOvernight`、`settingsSkipStatusOff`、`settingsSkipStatusOffHint`、`settingsSkipStatusNext`、`settingsSkipStatusNextHint`。状态文案的「持续至」与关态提示按同一份译法排版，不改词。
- 本轮只改两张跳过时段画板、画布索引与本文件；其他画板不动。
